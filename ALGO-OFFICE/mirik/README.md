# 👑 Мирик — старший ИИ-агент

Telegram-бот + админка в виде пиксельного офиса, где ИИ-сотрудники ходят, пьют кофе, садятся за столы и работают над твоими заданиями.

## Команда

| Агент | Роль | Умеет |
|---|---|---|
| 👑 Мирик | Руководитель | Общается с тобой, разбивает задачи, раздаёт команде (параллельно), помнит факты о тебе |
| 💻 Тимур | Программист | Пишет и запускает код (python / js / bash), создаёт файлы и проекты |
| 🔎 Лиза | Исследователь | Ищет в интернете, читает сайты, проверяет факты |
| 🌐 Боря | Оператор браузера | Настоящий Chromium: заходит на сайты, логинится, кликает, скачивает задания, шлёт скриншоты |
| 📚 Ника | Отличница | Решает домашку, задачи, пишет тексты, эссе, переводы |

Модель: `z-ai/glm-5.3-flash` через OpenRouter (понимает картинки — можно кидать фото заданий).

## Telegram

- Просто пиши задание — Мирик раздаст его команде, по ходу видно живой статус и кнопку «Стоп»
- Голосовые, аудио и кружочки → Мирик отправляет Сане (`/link/transcribe`), тот расшифровывает, дальше работает только GLM
- Фото → Мирик смотрит на картинку; файлы → попадают в `inbox/` рабочей папки
- `/timur`, `/liza`, `/borya`, `/nika` + текст — задание напрямую сотруднику
- `/secret имя значение` — логин/пароль для сайтов. Сообщение сразу удаляется, агенты вводят секрет в форму, **не видя значения**
- `/team`, `/tasks`, `/stop`, `/memory`, `/files`, `/get путь`, `/reset`, `/stats`
- Кнопка «Офис» открывает админку прямо в Telegram (Mini App, вход без пароля для владельца)

Пример: `/secret school_login ivanov`, `/secret school_pass ****`, затем «зайди на school.example.com, выгрузи домашку на завтра и реши».

## Офис (админка)

`http://localhost:8080` (или твой fly.io адрес). Клик по человечку — карточка агента, справа — задания с шагами, лента событий, команда. Внизу — поле для задания любому агенту. Окна показывают реальное время суток.

## Запуск локально

```bash
cp .env.example .env   # впиши ключи
npm install
npx playwright install chromium
npm run dev
```

## Деплой на fly.io

```bash
fly apps create mirik-hq
fly volumes create mirik_data --size 1 --region fra
fly secrets set OPENROUTER_API_KEY=... TELEGRAM_BOT_TOKEN=... ADMIN_PASSWORD=... OWNER_IDS=123456 PUBLIC_URL=https://mirik-hq.fly.dev
fly deploy
```

1 ГБ RAM нужен для Chromium. Если `OWNER_IDS` пуст — владельцем станет первый, кто напишет боту.

## Структура

```
src/agents/registry.js   — команда: роли, промпты, инструменты, места в офисе
src/agents/runtime.js    — цикл агента, делегирование, задачи
src/tools/               — web (поиск/чтение), files (код/файлы), browser (Playwright)
src/bot.js               — Telegram-бот
src/server.js            — API + WebSocket офиса
public/office.js         — игровой движок офиса (canvas)
public/app.js            — интерфейс админки
```

Новый сотрудник = новая запись в `registry.js` (имя, роль, инструменты, стол) — в офисе он появится сам.
