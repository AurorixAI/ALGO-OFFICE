# 👑 Algo Office

Веб-офис ИИ-сотрудников в виде пиксельной игры: человечки ходят, пьют кофе, садятся за столы и работают над твоими заданиями. Ты общаешься с Арсланом в чате прямо в офисе, он раздаёт задачи команде и присылает результат.

## Команда

| Отдел | Агент | Умеет |
|---|---|---|
| 👑 Руководство | Арслан | Общается с тобой, разбивает задачи, раздаёт команде (параллельно), помнит факты о тебе |
| 🏢 Операционный | 💻 Прометей — программист | Пишет и запускает код (python / js / bash), создаёт файлы и проекты |
| | 🔎 Артемида — исследователь | Ищет в интернете, читает сайты, проверяет факты |
| | 🌐 Гермес — оператор браузера | Настоящий Chromium: заходит на сайты, логинится, кликает, скачивает задания, делает скриншоты |
| | 📚 Афина — отличница | Решает домашку, задачи, пишет тексты, эссе, переводы, оформляет в DOCX/PDF |
| 🎬 Ютуберы | 📈 Аполлон — продюсер | Тренды и конкуренты на YouTube, идея, название, описание, теги, обложка |
| | ✍️ Каллиопа — сценаристка | Сценарий и раскадровка `scenes.json` |
| | 🎞 Гефест — монтажёр | Собирает MP4 по раскадровке, озвучка и музыка, превью |
| 💼 StartupBase | Арес, Фемида — венчурные аналитики | Рынок и конкуренты; экономика и риски |
| | Афродита — клиент | Вживается в покупателя: нужна ли ему эта штука |
| | Зевс — инвестор | Вложил бы деньги и на каких условиях |

Модель: `z-ai/glm-5.3-flash` через OpenRouter (понимает картинки — можно прикреплять фото заданий).

## Офис

`http://localhost:8080` (или твой fly.io адрес), вход по паролю `ADMIN_PASSWORD`.

- **💬 Чат** — пиши задание Арслану или выбери сотрудника над полем ввода. Видно живой ход работы, есть кнопки «Пауза», «Отменить», «Повторить».
- **📎 Файлы** — скрепка, перетаскивание или вставка из буфера (Ctrl+V). Файлы ложатся в `inbox/` рабочей папки, картинки Арслан видит сам.
- **Результаты** — файлы, скриншоты, видео и сообщения о прогрессе приходят прямо в ответ агента: картинки и ролики смотрятся в чате, остальное скачивается.
- **⚙️ Доступы** — логины и пароли для сайтов (агенты вводят их в формы, **не видя значения**), долгая память Арслана, сброс диалога.
- **👥 Команда, 📡 Лента, 💰 Бюджет** — кто чем занят, события, баланс OpenRouter и расход.

Пример: в «Доступах» сохрани `eclass_login` и `eclass_pass`, затем в чате — «зайди в e-class, выгрузи домашку на завтра и реши».

## Запуск

### Вариант 1 — одной командой (Mac / Linux)

Нужен только [Node.js 22.13+](https://nodejs.org) (на Mac: `brew install node`). Для документов желателен Python 3, для роликов — ffmpeg (`brew install python ffmpeg`).

```bash
git clone https://github.com/AurorixAI/ALGO-OFFICE.git
cd ALGO-OFFICE
./start.sh
```

Скрипт сам поставит зависимости, Chromium и Python-библиотеки, создаст `.env` с паролем от офиса, **спросит ключ OpenRouter** (взять: https://openrouter.ai/keys) и откроет офис в браузере: http://localhost:8080. Пароль он напечатает (и он лежит в `.env`, строка `ADMIN_PASSWORD`).

Дальше запускать тем же `./start.sh` — повторно ничего не ставится. Ключ можно поменять в `.env` и перезапустить.

### Вариант 2 — Docker (Mac / Windows / Linux)

Всё нужное уже внутри образа.

```bash
cp .env.example .env      # впиши OPENROUTER_API_KEY и ADMIN_PASSWORD
docker compose up -d --build
```

Офис: http://localhost:8080. Данные хранятся в Docker-томе `algo_data`. Остановить: `docker compose down`.

### Модель через Azure (вместо OpenRouter)

Если модель (например, DeepSeek) развёрнута в Azure AI Foundry или Azure OpenAI, в `.env` вместо `OPENROUTER_API_KEY`:

```
LLM_PROVIDER=azure
AZURE_ENDPOINT=https://<ресурс>.services.ai.azure.com/models
AZURE_API_KEY=<ключ из портала: Keys and Endpoint>
MODEL=<имя деплоя модели>
```

В `AZURE_ENDPOINT` можно вставить и полный Target URI со страницы деплоя — версия API подставится сама. Модели должны уметь вызывать инструменты (tool calling). Если модель не видит картинки, прикреплённые фото ей не передаются, агент работает по именам файлов. Баланс во вкладке «Бюджет» в этом режиме не показывается — расходы смотри в портале Azure.

### Деплой на fly.io

```bash
fly apps create algo-office
fly volumes create algo_data --size 1 --region fra
fly secrets set OPENROUTER_API_KEY=... ADMIN_PASSWORD=... PUBLIC_URL=https://algo-office.fly.dev
fly deploy
```

1 ГБ RAM нужен для Chromium.

## Саня

Саня — отдельное приложение, личный ассистент владельца. Если заданы `SANYA_URL` и `AGENT_LINK_TOKEN`, Арслан может давать ему поручения (`ask_sanya`), а Саня — присылать задания Арслану (`/link/ask`) и передавать доступы (`/link/secrets`). Его задания видны в чате офиса с пометкой «🤝 Саня».

## Структура

```
src/agents/registry.js   — команда: роли, промпты, инструменты, места в офисе
src/agents/runtime.js    — цикл агента, делегирование, задачи, вложения
src/tools/               — web (поиск/чтение), files (код/файлы), browser (Playwright), docs, video
src/server.js            — API + WebSocket офиса
src/memdb.js, memory.js  — долгая память (SQLite + FTS5)
public/office.js         — игровой движок офиса (canvas)
public/app.js            — интерфейс: чат, файлы, доступы, бюджет
```

Новый сотрудник = новая запись в `registry.js` (имя, роль, инструменты, стол) — в офисе он появится сам.
