# 👑 Мирик — старший ИИ-агент

Веб-офис ИИ-сотрудников в виде пиксельной игры: человечки ходят, пьют кофе, садятся за столы и работают над твоими заданиями. Ты общаешься с Мириком в чате прямо в офисе, он раздаёт задачи команде и присылает результат.

## Команда

| Отдел | Агент | Умеет |
|---|---|---|
| 👑 Руководство | Мирик | Общается с тобой, разбивает задачи, раздаёт команде (параллельно), помнит факты о тебе |
| 🏢 Операционный | 💻 Тимур — программист | Пишет и запускает код (python / js / bash), создаёт файлы и проекты |
| | 🔎 Лиза — исследователь | Ищет в интернете, читает сайты, проверяет факты |
| | 🌐 Боря — оператор браузера | Настоящий Chromium: заходит на сайты, логинится, кликает, скачивает задания, делает скриншоты |
| | 📚 Ника — отличница | Решает домашку, задачи, пишет тексты, эссе, переводы, оформляет в DOCX/PDF |
| 🎬 Ютуберы | 📈 Влад — продюсер | Тренды и конкуренты на YouTube, идея, название, описание, теги, обложка |
| | ✍️ Арина — сценаристка | Сценарий и раскадровка `scenes.json` |
| | 🎞 Гоша — монтажёр | Собирает MP4 по раскадровке, озвучка и музыка, превью |
| 💼 StartupBase | Артём, Дина — венчурные аналитики | Рынок и конкуренты; экономика и риски |
| | Камила — клиент | Вживается в покупателя: нужна ли ему эта штука |
| | Бахтиёр — инвестор | Вложил бы деньги и на каких условиях |

Модель: `z-ai/glm-5.3-flash` через OpenRouter (понимает картинки — можно прикреплять фото заданий).

## Офис

`http://localhost:8080` (или твой fly.io адрес), вход по паролю `ADMIN_PASSWORD`.

- **💬 Чат** — пиши задание Мирику или выбери сотрудника над полем ввода. Видно живой ход работы, есть кнопки «Пауза», «Отменить», «Повторить».
- **📎 Файлы** — скрепка, перетаскивание или вставка из буфера (Ctrl+V). Файлы ложатся в `inbox/` рабочей папки, картинки Мирик видит сам.
- **Результаты** — файлы, скриншоты, видео и сообщения о прогрессе приходят прямо в ответ агента: картинки и ролики смотрятся в чате, остальное скачивается.
- **⚙️ Доступы** — логины и пароли для сайтов (агенты вводят их в формы, **не видя значения**), долгая память Мирика, сброс диалога.
- **👥 Команда, 📡 Лента, 💰 Бюджет** — кто чем занят, события, баланс OpenRouter и расход.

Пример: в «Доступах» сохрани `eclass_login` и `eclass_pass`, затем в чате — «зайди в e-class, выгрузи домашку на завтра и реши».

## Запуск локально

Нужен Node.js 22.5+ (используется встроенный `node:sqlite`), Python 3 и ffmpeg.

```bash
cp .env.example .env   # впиши OPENROUTER_API_KEY и ADMIN_PASSWORD
npm install
npx playwright install chromium
pip3 install pypdf python-docx python-pptx openpyxl
npm run dev
```

## Деплой на fly.io

```bash
fly apps create mirik-hq
fly volumes create mirik_data --size 1 --region fra
fly secrets set OPENROUTER_API_KEY=... ADMIN_PASSWORD=... PUBLIC_URL=https://mirik-hq.fly.dev
fly deploy
```

1 ГБ RAM нужен для Chromium. Если `ADMIN_PASSWORD` не задан, пароль генерируется при каждом запуске и печатается в лог.

## Саня

Саня — отдельное приложение, личный ассистент владельца. Если заданы `SANYA_URL` и `AGENT_LINK_TOKEN`, Мирик может давать ему поручения (`ask_sanya`), а Саня — присылать задания Мирику (`/link/ask`) и передавать доступы (`/link/secrets`). Его задания видны в чате офиса с пометкой «🤝 Саня».

## Структура

```
src/agents/registry.js   — команда: роли, промпты, инструменты, места в офисе
src/agents/runtime.js    — цикл агента, делегирование, задачи, вложения
src/tools/               — web (поиск/чтение), files (код/файлы), browser (Playwright), docs, video
src/server.js            — API + WebSocket офиса
src/memdb.js, memory.js  — долгая память (SQLite + FTS5)
public/office.js         — игровой движок офиса (canvas)
public/app.js            — интерфейс: чат, файлы, доступы, бюджет
```

Новый сотрудник = новая запись в `registry.js` (имя, роль, инструменты, стол) — в офисе он появится сам.
